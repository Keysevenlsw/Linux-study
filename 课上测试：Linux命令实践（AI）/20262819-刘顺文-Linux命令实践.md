## 一、学习内容

这次作业主要围绕 Linux 命令的基本结构、常用命令的使用，以及命令输出结果的理解展开。我把练习分为目录与文件查找、用户与帮助信息、文本输出与处理三部分，重点记录 `echo`、`od`、`sort` 的用法。对没有正常输出或出现报错的命令，需要结合运行环境判断原因，不能只根据有没有输出判断命令是否执行成功。

Linux 命令通常可以写成“命令名 选项 参数”的形式。例如，`ls -l /home` 中，`ls` 表示列出目录内容，`-l` 表示使用长格式，`/home` 是操作对象。选项和参数不一定都需要出现，部分命令的选项也不以短横线开头。

命令通常由 Shell 解释并执行，通过程序和系统调用使用操作系统提供的功能。其中，`cd` 是 Shell 内建命令，不是单独运行的外部程序。

## 三、常用命令实践

### 1. ls：查看目录内容

```bash
cd ~/linux-command-practice
ls
ls -a
ls -l
ls -lh
ls /etc
ls -t
ls -R
```

`ls -a` 可以显示隐藏项，`ls -l` 可以显示权限、所有者、大小等信息，`ls -lh` 将文件大小显示为便于阅读的单位。`ls -t` 按修改时间排序，`ls -R` 递归显示子目录。文件较小时，`-h` 的显示差异可能不明显。

### 2. who：查看登录信息

```bash
who
who am i
who -b
who -q
who -u
whoami
```

`who` 读取系统登录记录，`who am i` 查询与当前终端对应的登录记录，`who -b` 查询启动时间，`who -q` 显示登录记录及数量，`who -u` 显示空闲时间等信息。`whoami` 显示当前有效用户的用户名，与 `who am i` 的含义不同。

部分桌面终端或系统没有相应登录记录，`who` 或 `who am i` 可能不显示内容；同一用户多次登录也可能出现多条记录，因此登录记录数不能直接理解为不同用户的人数。

### 3. pwd 与 cd：查看和切换工作目录

```bash
cd ~/linux-command-practice
pwd
pwd -P
cd /home
pwd
cd ..
pwd
cd ~
pwd
cd -
pwd
cd ~/linux-command-practice/subdir
cd ../..
pwd
```

`pwd` 查看当前工作目录，`cd ..` 返回上一级，`cd ~` 返回个人主目录，`cd -` 返回上一次所在目录。没有经过符号链接时，`pwd` 和 `pwd -P` 的结果可能相同。

为了比较逻辑路径和物理路径，还可以创建一个实验用的目录链接。链接已存在时不必重复创建。

```bash
cd ~/linux-command-practice
ln -s subdir linkdir
cd linkdir
pwd -L
pwd -P
cd ~/linux-command-practice
```

### 4. man：查询帮助文档

```bash

```

### 6. find：按条件查找文件

```bash
cd ~/linux-command-practice
find /home -name "*.txt"
find . -type d
find . -size +10M
find / -mtime -7
```

查找 `/home` 或 `/` 时，普通用户可能遇到其他目录的权限限制。最后一条遍历范围较大，运行较久时可以用 `Ctrl+C` 中断并如实记录，再用下面的命令缩小范围完成观察：

```bash
find ~/linux-command-practice -mtime -7
dd if=/dev/zero of=~/linux-command-practice/large.bin bs=1M count=11
find ~/linux-command-practice -type f -size +10M
```

`dd` 在这里创建一个普通实验文件，输出路径不能改成磁盘设备。没有满足条件的文件时，`find` 不输出匹配结果属于正常情况。`-mtime -7` 按过去不足七个完整的 24 小时时段筛选；`-size` 的 `M` 以 1,048,576 字节为单位，并涉及单位取整，不宜简单等同于十进制 MB。

### 8. grep：查找文件中的文本

```bash
grep "root" /etc/passwd
grep -n "root" /etc/passwd
grep -i "Root" /etc/passwd
grep -v "nologin" /etc/passwd
grep -r "hello" /home
```

`-n` 显示行号，`-i` 忽略大小写，`-v` 输出不匹配的行，`-r` 递归搜索。搜索 `/home` 可能出现权限错误或较多输出，可以保留原结果后在实验目录内比较：

```bash
cd ~/linux-command-practice
grep -n "hello" sample.txt
grep -ni "hello" sample.txt
grep -rl "hello" ~/linux-command-practice
```

`grep -r` 默认输出匹配行；如果只需要匹配文件的名称，可以加 `-l`。无匹配时没有输出，并不一定是命令写错。

## 四、重点命令实践

### 1. echo：输出文字与变量

```bash
cd ~/linux-command-practice
echo "Hello Linux"
echo "$PATH"
echo "test content" > echo-test.txt
cat echo-test.txt
echo "new content" >> echo-test.txt
cat echo-test.txt
echo -n "no new line"
echo
echo "$HOME"
echo *.txt
```

这里用 `echo-test.txt` 对应原示例的 `test.txt`，避免覆盖排序练习数据。`>` 覆盖文件，`>>` 追加到末尾；`echo -n` 不自动换行，紧接着的 `echo` 用于补一个换行。变量加双引号可以避免不必要的分词和通配符展开。`echo *.txt` 中的文件名展开由 Shell 完成。

### 2. od：按不同格式查看文件内容

```bash
cd ~/linux-command-practice
od -c test.bin
od -x test.bin
od -d test.bin
od -t x1 test.bin
od -A x test.bin
od -A x -t x1 test.bin
od -An -t x1 -N 16 /usr/bin/ls
```

实验文件开头是字符 `ABC`，随后是预先写入的特殊字节。`-c` 按字符形式显示，`-x` 和 `-d` 默认以双字节单元显示十六进制和无符号十进制值，结果会受到字节序影响；`-t x1` 按单字节显示十六进制值，更方便逐字节比较。

`-A x` 只把左侧偏移地址改成十六进制，并不会同时把文件内容改成十六进制。最后一条只读取 `/usr/bin/ls` 的前 16 个字节；在常见 Ubuntu 环境中，ELF 文件的起始字节应为 `7f 45 4c 46`。

### 3. sort：排序与去重

```bash
cd ~/linux-command-practice
cat test.txt
sort test.txt
sort -n number.txt
sort -r test.txt
sort -k 2 scores.txt
sort -u test.txt
sort -k 2,2n scores.txt
sort -nr number.txt
```

第二列排序使用单独准备的 `scores.txt`。普通文本排序和数值排序不同，例如字符串比较时 `10` 可能排在 `2` 前面，而 `-n` 按数值比较。`-r` 反转排序顺序，`-u` 在排序时去除重复行，`-nr` 按数值降序排列。

`sort -k 2` 的排序键从第二字段一直延伸到行尾。如果要严格限定第二字段并按数值排序，应使用 `sort -k 2,2n scores.txt`。默认排序还受语言区域设置影响，需要固定字节排序规则时可使用 `LC_ALL=C sort test.txt`。这些命令默认输出结果，不直接修改原文件。

## 六、学习材料中的修正

整理示例时，我认为下面几处需要补充说明。

| 原材料中的表述或示例 | 修正或补充 |
| --- | --- |
| 命令名就是调用的程序名称 | 命令也可能是 Shell 内建命令，例如 `cd`；命令通常通过 Shell 和程序使用系统功能。 |
| `cd \~` | 在终端中应输入 `cd ~`。如果将反斜杠也输入，波浪号不会按通常方式展开为主目录。 |
| `find /home -name "\*.txt"` | 本练习统一写成 `find /home -name "*.txt"`，双引号已经能防止 Shell 展开通配符；不要把排版转义误当作必须输入的命令字符。 |
| `locate \*.md` | 可以统一写成 `locate '*.md'`，更容易看清完整搜索模式。原来的反斜杠写法也能阻止 Shell 展开，不能一概判为错误。 |
| `who am i` 表示当前用户 | 它依赖当前终端的登录记录，可能为空；查询当前有效用户名称应用 `whoami`。 |
| `who -q` 统计用户总数 | 应区分登录会话记录数与不同用户人数，同一个用户可能有多条登录记录。 |
| `which python` | 系统可能只有 `python3`；无结果时先检查命令是否存在，不能据此断定没有安装任何 Python。 |
| `find / -mtime -7` | 遍历范围较大，普通用户可能无权访问部分目录；应保留错误并说明，也可以在个人实验目录补充练习。 |
| `grep -r` 搜索包含文字的文件 | 默认展示匹配行；只列出文件名时应使用 `grep -rl`。 |
| `od -A x` | 只改变偏移地址格式；内容格式需要用 `-t` 等选项指定。 |
| `sort -k 2` 按第二列排序 | 排序键实际从第二字段延伸至行尾；仅按第二字段数值排序可用 `-k 2,2n`。 |
